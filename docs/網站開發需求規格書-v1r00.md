# 長榮登山社校友會遊記網站 — 開發需求規格書

**版本：** v1r00
**日期：** 2026-08-02
**技術棧：** Next.js (React) + 前端靜態網站
**資料來源：** `stories/` 目錄（36 篇遊記 + 前言 + 後記）

---

## 一、專案目的

將長榮登山社校友會 10 週年紀念遊記總集，轉化為一個以**時間軸為骨架、故事卡為內容單位、照片為敘事證據**的前端網站。

使用者不是在閱讀一條活動清單，而是沿著時間前進，每到一個活動節點，就打開一張可獨立閱讀的故事卡，並透過照片直接感受當時的山行經歷。

### 設計理念來源

參考 [Anne Frank Timeline](https://www.annefrank.org/en/anne-frank/the-timeline/) 與本專案 `UIDesignStudy/UI Research1-v1r00.md` 提出的「時間證據卡（Timeline Evidence Cards）」概念：

> **以時間控制故事節奏，以故事卡承載每個事件，並讓照片成為推動故事前進的核心證據。**

### 三層架構

| 層次 | 對應概念 | 使用者問題 | 本專案對應 |
| --- | --- | --- | --- |
| 時間層 | 時間是敘事介面 | 接下來發生什麼？ | 民國 87–95 年活動時間軸 |
| 故事層 | 每個事件是獨立故事卡 | 這個活動發生了什麼？ | 每篇遊記 Markdown |
| 證據層 | 史料是故事的一部分 | 我們怎麼知道？ | 活動照片（`images/` 目錄） |

## 二、資料現況分析

### 2.1 資料目錄結構

```
stories/
├── 前言/前言.md              # 含活動年表（44 筆活動紀錄）
├── 後記/後記.md              # 出版資訊、作者群
├── 87年/
│   ├── 00月/陽明山國家公園/   # 日期不明
│   │   ├── 陽明山國家公園.md
│   │   └── images/*.jpeg
│   └── 05月/烏山/
│       ├── 烏山.md
│       └── images/*.jpeg
├── 88年/…
│   └── …（至 95 年）
└── 95年/09月/茶壺山與金瓜石/
```

### 2.2 遊記檔案結構（Markdown）

每篇遊記 Markdown 具有以下特徵：

- **標題：** `# 活動名稱`
- **日期標記：** `> 民國XX年XX月`（blockquote）
- **作者標記：** 行內粗體，如 `**87年5月23~24日 烏山  謝兆光**`
- **內文：** 段落文字，含登山過程敘述
- **內嵌圖片：** `![imageN.jpeg](images/imageN.jpeg)`，圖片儲存於同層 `images/` 子目錄
- **部分含子章節：** `## 山行軼事－…`、`**ＤＡＹⅠ**`、`**後記：…**` 等
- **部分含表格：** 如伙食表、活動年表

### 2.3 活動年表（前言.md）

`前言.md` 內含一張 44 筆紀錄的活動年表，欄位為：

| 欄位 | 說明 | 範例 |
| --- | --- | --- |
| 序號 | 活動編號 | 1, 2, 3… |
| 活動時間 | 民國年月日 | 87年5月23~24日 |
| 活動地點 | 山岳/景點名 | 烏山 |
| 參加人數 | 數字或空 | 14 |
| 備註 | 附加說明 | 召開會員大會、因颱風取消等 |

此年表是時間軸的主要資料來源，涵蓋已取消活動（參加人數 0），可作為「證據缺口」的展示素材。

### 2.4 資料規模統計

- 遊記檔案：36 篇（含前言、後記共 38 個 Markdown）
- 年份範圍：民國 87 年 – 95 年
- 活動紀錄：44 筆（含已取消 4 筆）
- 圖片：每篇 3–23 張不等，總計約 250 張 JPEG

## 三、功能需求

### 3.1 頁面架構

```
首頁（Landing）
├── 時間軸頁面（Timeline）         # 主視圖，全活動總覽
├── 故事卡詳細頁（Story Detail）    # 單篇遊記
├── 證據檢視頁（Evidence Viewer）   # 單張照片深度檢視
├── 前言頁（Preface）              # 活動年表、指導老師的話
├── 後記頁（Afterword）            # 出版資訊、作者群
└── 關於頁（About）                # 網站說明、設計理念
```

### 3.2 首頁（Landing Page）

**目的：** 建立情境，引導使用者進入時間軸。

- 全幅山景意象圖或精選活動照片輪播
- 網站標題：「長榮登山社校友會 10 週年遊記」
- 副標題：一句話點出設計理念（「沿著時間，走進每一段山行故事」）
- 主視覺下方放置「進入時間軸」按鈕，連至 `/timeline`
- 底部放置前言、後記、關於的連結

### 3.3 時間軸頁面（Timeline）— 核心頁面

**目的：** 以時間為骨架呈現所有活動，控制敘事節奏。

#### 3.3.1 時間軸視覺

- 水平時間軸，由左至右依年代排列：`87年 ─── 88年 ─── … ─── 95年`
- 每個活動以節點呈現，節點視覺權重區分：
  - **大圓點：** 重要活動（會員大會、交接典禮、老師慶生）
  - **小圓點：** 一般活動
  - **警示符號（灰色/叉號）：** 因颱風或人數不足取消的活動
  - **文件符號：** 含豐富照片的活動（照片 ≥ 10 張）
- 年份標籤固定於軸上，可作為跳轉錨點

#### 3.3.2 互動行為

- **捲動導覽：** 水平捲動或拖曳時間軸，節點隨之滑過
- **點擊節點：** 展開該活動的故事卡摘要（側邊面板或卡片浮層），顯示：
  - 活動名稱
  - 日期
  - 地點
  - 一句話摘要（自動截取遊記首段或由前言年表備註取得）
  - 照片縮圖預覽（前 3 張）
  - 「閱讀完整故事」按鈕 → 連至 `/story/[id]`
- **年份快速跳轉：** 顶部年份標籤可點擊跳轉至該年第一個活動
- **縮放控制：** 可展開/收起時間軸密度（全年總覽 vs 單年詳細）

#### 3.3.3 雙時間對照（進階功能，Phase 2）

參考 UI Research 的「雙時間閱讀」概念：

- 上排：社團活動時間軸
- 下排（可選開啟）：台灣登山史大事紀（如：玉山國家公園成立、登山政策變遷）

> 此功能為 Phase 2 擴充，MVP 不含。

### 3.4 故事卡詳細頁（Story Detail）

**目的：** 完整呈現單篇遊記，照片嵌入閱讀流程。

**路由：** `/story/[storyId]`

#### 3.4.1 頁面結構

```
┌─────────────────────────────────────┐
│  [← 返回時間軸]                     │
│                                     │
│  民國 92 年 10 月                    │
│  合歡北峰-天巒池縱走                  │
│  作者：XXX、XXX                      │
│  地點：合歡山                         │
│                                     │
│  ─── 故事本文 ───                    │
│  （段落文字 + 內嵌照片）              │
│                                     │
│  [照片可點擊放大 → 證據檢視頁]       │
│                                     │
│  ← 上一個活動        下一活動 →      │
└─────────────────────────────────────┘
```

#### 3.4.2 內容呈現規則

- **Markdown 渲染：** 使用 MDX 或 react-markdown 渲染遊記原文
- **圖片處理：** Markdown 中的 `![imageN.jpeg](images/imageN.jpeg)` 渲染為：
  - 響應式圖片，最大寬度受限於文章欄位
  - 可點擊進入證據檢視頁（Lightbox 或獨立路由）
  - 圖片下方可選顯示 caption（若有可推導的說明文字）
- **子章節：** 保留原文的 `##` 標題與 `**DAYⅠ**` 等粗體段落標記，轉為視覺區塊
- **表格：** 保留並響應式渲染（如伙食表、活動年表）
- **前後導航：** 頁面底部顯示前一篇/後一篇活動連結（依時間順序）
- **側邊目錄（可選）：** 長篇遊記（如雪山東主峰）顯示章節快速跳轉

#### 3.4.3 故事卡資料模型

每篇故事卡對應以下資料結構：

```typescript
interface StoryCard {
  storyId: string;          // slug，如 "92-10-hehuan-north-peak"
  title: string;            // 活動名稱
  year: number;             // 民國年，如 92
  yearLabel: string;        // "92年"
  month: number | null;     // 月，如 10（00月=日期不明）
  monthLabel: string;       // "10月"
  fullDateLabel: string;    // "民國92年10月"
  location: string;         // 地點（從年表或遊記推導）
  authors: string[];        // 作者群
  attendees: number | null; // 參加人數（從年表）
  note: string | null;      // 備註（從年表，如「召開會員大會」）
  isCancelled: boolean;     // 是否取消
  summary: string;          // 一句話摘要
  contentMarkdown: string;  // 原始 Markdown 內容
  imageIds: string[];       // 圖片檔名列表
  sequenceNumber: number;   // 年表序號
  prevStoryId: string | null;
  nextStoryId: string | null;
}
```

### 3.5 證據檢視頁（Evidence Viewer）

**目的：** 單張照片深度檢視，對應 UI Research 的「第三層：從史料進入深度探索」。

#### 3.5.1 互動方式

- **Lightbox 模式（Phase 1）：** 在故事卡頁內點擊照片，彈出全螢幕 Lightbox，顯示原圖，可左右切換同篇遊記的照片
- **獨立路由（Phase 2）：** `/story/[storyId]/image/[imageId]`，可分享單張照片連結

#### 3.5.2 證據資料模型

```typescript
interface Evidence {
  evidenceId: string;       // "92-10-hehuan-image42"
  storyId: string;          // 所屬故事卡
  fileName: string;         // "image42.jpeg"
  imageUrl: string;          // 優化後的圖片路徑
  altText: string;           // 無障礙替代文字
  caption: string | null;    // 說明文字（若有）
  contextParagraph: string | null; // 圖片前後段落文字
  order: number;             // 在故事中的順序
}
```

### 3.6 前言頁（Preface）

**路由：** `/preface`

- 呈現「指導老師的話」「會長的話」「副會長的話」（原文為手寫圖片，標註「本節內容為手寫/圖片形式」）
- 完整活動年表，以響應式表格呈現
- 年表可點擊任一活動列，跳轉至對應故事卡
- 「編者的話」「作者的話」「照片集錦」（若有圖片則呈現）

### 3.7 後記頁（Afterword）

**路由：** `/afterword`

- 呈現後記全文（如「曾經 — 顏彤」）
- 出版資訊：發行人、策劃、撰文、總編輯、攝影、出版者、初版日期、刷數、非賣品標示
- 作者群列表可視化

### 3.8 關於頁（About）

**路由：** `/about`

- 網站設計理念說明（時間證據卡概念）
- 資料來源說明
- 技術棧說明

## 四、資料處理需求

### 4.1 資料建構流程

因資料來源為 Markdown 檔案與目錄結構，需在建構時（build time）解析並轉為結構化資料：

```
stories/ 目錄
    ↓ Node.js 腳本解析
    ↓
結構化 JSON（stories.json + evidence.json）
    ↓
Next.js getStaticProps / getStaticPaths
    ↓
靜態頁面
```

### 4.2 解析規則

1. **目錄結構 → 時間資訊：**
   - `stories/92年/10月/合歡北峰-天巒池縱走/` → year=92, month=10
   - `00月` 表示日期不明（如陽明山國家公園）
   
2. **Markdown 前行 → 作者與標題：**
   - `# 合歡北峰-天巒池縱走` → title
   - `> 民國92年10月` → 日期確認
   - `**87年5月23~24日 烏山  謝兆光**` → 解析出作者與詳細日期

3. **Markdown 內嵌圖片 → 證據清單：**
   - 正規表達式匹配 `!\[([^\]]*)\]\((images/[^)]+)\)`
   - 提取圖片檔名、alt 文字、在文中的順序

4. **前言年表 → 活動後設資料：**
   - 解析 Markdown 表格，取得序號、時間、地點、人數、備註
   - 以地點名稱關聯至對應的故事卡
   - 標記 `參加人數 = 0` 的活動為 `isCancelled = true`

5. **取消活動（無遊記檔案）：**
   - 年表中「因颱風取消」「報名人數過少」等活動無對應 Markdown
   - 時間軸上仍顯示節點（灰色/叉號），點擊顯示「此活動因故取消」說明

### 4.3 地點-故事關聯策略

年表活動地點名與資料夾活動名可能不完全一致，需建立對應表：

| 年表地點 | 資料夾/遊記名 |
| --- | --- |
| 烏山 | 烏山 |
| 石洞溫泉 | 石洞溫泉之旅 |
| 桶盤山 & 烏來山 | 桶盤山與烏來山 |
| 合歡北峰-天巒池縱走 | 合歡北峰-天巒池縱走 |
| 雪山東主峰 | 雪山東主峰 |

> 建議以 `序號` 為主鍵，手動建立 `序號 → storyId` 對應表，確保準確性。

### 4.4 圖片優化

- 原圖為 JPEG，尺寸不一，需在建構時或部署時進行優化：
  - 產生縮圖（thumbnail, 400px）、中圖（800px）、原圖三種尺寸
  - 使用 Next.js `<Image>` 元件自動處理響應式與 lazy loading
  - 考慮使用 `next/image` 的內建優化或預先產生 WebP 版本

## 五、技術架構

### 5.1 技術棧

| 項目 | 選擇 | 說明 |
| --- | --- | --- |
| 框架 | Next.js 14+ (App Router) | 靜態匯出（`output: 'export'`） |

### 5.3 靜態匯出考量

- `next.config.js` 設定 `output: 'export'`
- 所有頁面使用 `generateStaticParams` 預先生成
- 圖片若使用 `next/image` 靜態匯出需設定 `unoptimized: true` 或預先優化
- 路由不含查詢參數，全部使用動態路由參數

## 六、UI/UX 設計規格

### 6.1 整體風格

- **基調：** 山林意象、溫潤沉穩
- **色彩：**
  - 主色：深林綠（`#2d5016` 附近）
  - 輔色：山岩褐、晨霧灰
  - 背景：米白/淺米色（紙質感）
  - 強調色：楓紅或秋金（用於重要節點）
- **字體：** 中文使用 Noto Serif TC（襯線體，呼應紙本遊記質感）+ 英文/數字使用 Inter
- **質感：** 微微的紙張紋理背景，照片帶柔和陰影或白邊框（相本感）

### 6.2 響應式設計

| 斷點 | 裝置 | 時間軸呈現 | 故事卡呈現 |
| --- | --- | --- | --- |
| ≥1024px | 桌面 | 水平時間軸，可見全年代 | 雙欄（文+圖）或單欄寬版 |
| 768–1023px | 平板 | 水平時間軸，可滑動 | 單欄 |
| <768px | 手機 | 垂直時間軸或水平滑動 | 單欄，圖片全寬 |

### 6.3 無障礙

- 圖片需有 `alt` 文字（從 Markdown alt 或遊記上下文推導）
- 時間軸節點需鍵盤可操作（Tab + Enter）
- 色彩對比符合 WCAG AA
- Lightbox 支援 Esc 關閉、方向鍵切換

### 6.4 載入效能

- 圖片 lazy loading
- 時間軸初次載入只渲染可視範圍節點（virtualization）
- 靜態匯出無 hydration 負擔，首頁 LCP < 2s

## 七、開發階段規劃

### Phase 1：MVP（最小可行產品）

**目標：** 一條時間軸 + 所有故事卡 + 照片瀏覽

1. **資料建構腳本**
   - 解析 `stories/` 目錄與 Markdown
   - 產生 `stories.json`、`evidence.json`、`timeline.json`
   - 建立序號-故事對應表

2. **基礎頁面**
   - 首頁
   - 時間軸頁面（水平時間軸 + 節點點擊展開摘要）
   - 故事卡詳細頁（Markdown 渲染 + 圖片 Lightbox）
   - 前言頁、後記頁

3. **核心互動**
   - 時間軸節點點擊 → 故事卡摘要 → 完整故事
   - 故事卡內圖片點擊 → Lightbox 放大

## 九、已知限制與假設

1. **手寫內容無法數位化：** 前言中「指導老師的話」「會長的話」「副會長的話」原文為手寫圖片，本網站標註為「手寫/圖片形式」，不嘗試 OCR。
2. **部分活動無遊記：** 年表 44 筆中，僅 36 篇有對應 Markdown 遊記，其餘以年表資訊呈現。
3. **民國年與西元年對照：** 民國 87 年 = 西元 1998 年；網站可選擇顯示民國年或同時顯示兩者。
4. **圖片說明文字有限：** 原始 Markdown 圖片 alt 僅為檔名（如 `image42.jpeg`），無詳細說明。caption 需從前後文推導或留空。
5. **序號 24 缺漏：** 年表序號跳過 24（92年7月水社大山後直接到 25），推測為編號疏漏，網站如實呈現。
6. **地點-故事對應需人工校驗：** 年表地點名與資料夾名稱可能不一致，需建立並維護對應表。
