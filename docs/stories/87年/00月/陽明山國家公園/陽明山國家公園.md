# 陽明山國家公園

> 民國87年

**87年月~日 陽明山國家公園                                 謝兆光**

這次活動的第一個感覺是神奇，第二個感覺是「濕」。第一個感覺是因為這次參加的組合很奇怪，有老師、師母（當然這並不奇怪，怪是怪在接下來這些人）、Bingo、阿光、美怡、大姊頭、大姊頭的同學、鴨子、曾雅琪以及Kiki，傑克這的太神奇了！這樣組合的機率可以請為理算一算到底有多低。

活動的前一個晚上住在淡水捷運站前的萬X大飯店（為了防止有廣告嫌疑所以不登全名，其實是我忘記了）。那天晚上在淡水老街生平第一次嚐到鼎鼎有名的阿給，吃完晚餐後一群人浩浩蕩蕩的到淡水的街上血拚，什麼魚穌、阿媽的酸梅湯等都買了，恰好碰到宜蘭文旦特賣會，還買了一大箱的文旦回旅社內準備隔天爬山時解饞用。記得當天一群女生還在服飾店內流連忘返，一直到店家要關門了才不捨的離去。

隔天一大清早，飄著綿綿的細雨，坐著公車到山上後，開始了悲慘的一天。或許辦公桌坐太久了，一把老骨頭走不了多久就氣喘如牛，而且有數不完的階梯，爬完一段又一段，心中暗自偷罵：「為何台北的登山步道都要用階梯，是誰想出的餿主意？」而且昨晚買的文旦好像又長大了，一個變兩個，兩個變四個。

天氣雖然不好，但途中還遇到不少假日上山的「哦巴桑」媽媽們，直說年輕人不錯、體力好，我只有苦笑回應。中餐在山中的涼亭解決，好險老師有帶火機和鍋子，使我們有熱熱的泡麵可以吃，要不然就只能啃乾乾的麵包了。餐後的路程並不難走，但天氣卻不怎麼好，所以上了七星山後老師就決定要提早回晚上休息的活動中心。但山上的強風及大雨，卻讓我們下山時身上溼透了，不過讓我覺得神奇的是竟然還有一些年輕人在這種天氣下還在山上的涼亭裡烤肉。

到達活動中心後不久，原因有事的佳靜及春燕也帶著補給品來探望我們著些狼狽的登山客。後來晚上大家才把那些文旦拿出來消化掉，吃完後滿地的文旦皮才覺得我們真的發瘋背了這麼多文旦上來幹麼！其實，這次活動最辛苦的是Bingo同學，整段活動從路程規劃，食宿及交通安排，他都全程包辦，真該謝謝他，希望他有朝能成功回來。
