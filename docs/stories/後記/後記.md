# 後記

曾經                          顏彤

偶爾在繁雜忙碌的生活中停下來時，腦中會突然閃過一些片段的畫面--這個地方熟悉，好像是……？這裡好像是……？還是……？我好像是跟誰來過？到底是什麼時候來的？一個一個的問號接連的浮現出來。明明是去過的地方，為什麼記憶卻是如此模糊，模糊到這究竟是真實存在過抑或只是夢境？

人生的路是一直往前走，沒有回頭的；但我們都太在意向前看、往前走，卻容易將走過之後的痕跡死鎖在記憶的寶庫裡。時間一久，寶庫的東西越塞越多，但打開寶庫的鑰匙卻不知丟哪兒去，要上哪而找。

「對的事情就要堅持」很高興我們都一起堅持下去，一起創造寶庫裡的寶藏，也堅持共同打造寶庫的鑰匙--會訊（遊記）。

夥伴們，你有多久沒打開你塵封已久的寶庫，欣賞曾經收藏的寶藏呢？別再讓灰塵埋沒了你的寶藏！
